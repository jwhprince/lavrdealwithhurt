# VOLTA design standards

Priority: agreed user brief, accessibility and responsive behavior, then decorative effects. Pair with SKILL1.md.

- Preserve the eight agreed sections and supplied original photographs. Never invent testimonials, schedules, prices or qualifications.
- Use the logo's pale rose and burgundy palette, responsive generous spacing and full Cyrillic typography.
- Hero: text left / logo right on wide screens, stacked on mobile. Heading line counts are desktop targets, never a reason to clip mobile text.
- The third section has a flat pale-pink background and text only.
- No random layout selection, simulated tool execution or mandatory component arsenal.
- No stock placeholders or replacement photography without an explicit request.
- Motion is optional and subtle. No mandatory GSAP, pinned scrolling, horizontal scrolling or content hidden pending JavaScript. Respect prefers-reduced-motion.
- Keyboard-accessible controls, visible focus, WCAG AA contrast, generous touch targets.
- Images need intentional responsive cropping, explicit dimensions and useful alt text. Never distort the logo.
- Verify composition, readable controls, mobile overflow and image crops in a real browser before claiming validation.
